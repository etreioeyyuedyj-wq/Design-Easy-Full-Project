# DEFP Syntax

DEFP (Design Easy Full Project) is a beginner-friendly programming language concept.

## 1. Say

The `say` command displays text or a value.

Example:

say "Hello World"

## 2. Variables

The `set` command creates a variable.

Example:

set name = "Rohan"
say name

## 3. Basic Calculations

DEFP can use basic arithmetic operators.

Example:

set a = 10
set b = 5

say a + b
say a - b
say a * b
say a / b

## Commands

| Command | Purpose |
|---|---|
| `say` | Display output |
| `set` | Create a variable |

## Operators

| Operator | Meaning |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
