# DEFP Language Specification

## 1. Language Name

DEFP

DEFP is the name and identity of the programming language.

`DEFP` itself is not a command or function.

## 2. Mandatory Symbol

The `<>` symbol is mandatory in DEFP syntax.

If the required `<>` structure is missing, the DEFP program should not be considered valid.
