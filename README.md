## ⭐ What is DEFP?

DEFP is the name and identity of the programming language.

DEFP itself is not a command or function.

The language is being designed with its own syntax and rules.

---

## 🔹 Core Syntax

The `<>` structure is a mandatory part of DEFP syntax.

Without the required `<>` structure, DEFP code is not valid.
